

bookmarks.json is the definitive file obtained by extracting as JSON
bookmarks from firefox and brave, unifying them, then de
duplicating. Then move into bookmarks.json and now manually
maintaining that.

## clear_firefox.py

Removes all bookmarks from Firefox

## update_bookmarks.py

Replaces current bookmarks with those from bookmarks.json

## unify_bookmars.py

Read and save as JSON firefox and brave bookmarks, then unify them
into dookmarks_unified.json
